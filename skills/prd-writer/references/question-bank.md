# Question Bank

Pick 3-5 questions for the detected archetype. Skip any already answered by the user's prompt. Always add quick options in parentheses. Translate to the user's language.

## Always consider (pick the most relevant)
1. **Core goal & target user:** Who is the main user and what outcome must they achieve? (e.g., consumers / small business / internal team)
2. **MVP boundary:** What must be in Phase 1 vs later? (e.g., core only / core + payments / full)
3. **Platform & stack constraints:** Where will it run, and any preferred tech? (e.g., web / iOS+Android / desktop; React / Laravel / no preference)

## SaaS / Web App
- User roles and permissions? (single role / admin + user / multi-tenant orgs)
- Monetization? (free / subscription / one-time / usage-based)
- Must-have integrations? (payment gateway / email / OAuth / none)

## Mobile App
- Offline support needed? (none / read-only / full sync)
- Native features? (camera / GPS / push notifications / biometrics)
- Cross-platform or native? (Flutter / React Native / Swift+Kotlin)

## 3D / Interactive Web
- Interaction model? (scroll-driven / mouse / touch / VR)
- Asset source? (existing models / need to be created / procedural)
- Performance target? (desktop only / mid-range mobile too)

## AI Agent / Bot
- Which tools or APIs must the agent call? (search / database / calendar / custom)
- Memory needs? (stateless / session / long-term)
- Channel? (web chat / WhatsApp / Telegram / API / CLI)
- Human-in-the-loop for risky actions? (none / approval / full review)

## Game
- Genre and core loop? (puzzle / idle / RPG / platformer)
- Single or multiplayer? (solo / local / online)
- Engine / platform? (Unity / Godot / web canvas / mobile)

## CLI / Plugin / Library
- Primary users and environment? (developers / sysadmins; Node / Python / Go)
- Distribution? (npm / pip / binary / VS Code marketplace)

## Enterprise / Internal System
- Existing systems to integrate with? (ERP / SSO / legacy DB)
- Compliance or audit requirements? (none / GDPR / ISO / industry-specific)
- Expected users and data volume? (<100 / thousands / large scale)

## Closing line (always include)
"Answer only the points you've already decided, or reply **'build directly'** / **'buat langsung'** to use best standard defaults."
