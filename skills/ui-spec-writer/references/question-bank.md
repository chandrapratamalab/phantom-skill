# Visual Direction Question Bank

Pick 3-5. Skip anything the PRD or user already answered (platform, audience, features). Add quick options in parentheses. Match the user's language.

## Always consider
1. **Mood:** How should it feel? (calm and trustworthy / energetic and playful / premium and minimal / utilitarian and dense)
2. **References:** Any apps or sites whose look you like or dislike? (names / none)
3. **Brand assets:** Existing logo, colors, or fonts to keep? (yes, will share / none, you decide)
4. **Theme:** Light only, dark only, or both? (light / dark / both)

## By product type
- **SaaS / dashboard:** Data density? (spacious / balanced / dense). Primary device? (desktop / tablet / mobile).
- **Mobile app:** Navigation preference? (bottom tabs / drawer / single flow). One-handed use important? (yes / no).
- **E-commerce / marketplace:** Photo-led or text-led product display? Trust signals to emphasize? (reviews / badges / guarantees).
- **Content / education:** Reading-heavy or interactive? Age range of users?
- **3D / interactive web:** Should the UI frame stay minimal over the scene? (minimal overlay / full interface). Reduced-motion fallback needed? (yes / no).
- **AI agent / chat:** Chat only, or chat plus side panels (sources, tools, history)? Show tool activity to the user? (hidden / summarized / full).
- **Game:** HUD style? (minimal / rich / diegetic). Input? (touch / keyboard / controller).
- **Enterprise / internal:** Existing design system to follow? (company system / none). Heavy tables and forms? (yes / few).

## Closing line (always include)
"Answer only what you've decided, or reply **'build directly'** / **'buat langsung'** and I'll choose a fitting direction and list it as an assumption."
